# Harness Kit v0.5.0

发布日期：2026-11-11。用户可直接安装自包含 Skill、Codex/Claude Code 插件或 DSH 原生插件，再用自然语言接入项目与执行验证，**无需运行 bun setup**。Bun ≥ 1.3.4 仍是执行依赖。

## 本版新增

- 独立 Skill ZIP，包含完整 CLI 脚本；不依赖源码目录或全局 harness 短命令。
- Codex/Claude 共用本地 marketplace 包，分别包含宿主识别的插件与来源清单。
- DSH 原生 Cordis 插件，向 skills 服务注册内置 Skill，正文按需读取，随插件卸载撤销注册。
- 一条作者命令生成三套目录、三个 ZIP、安装说明、文件清单和 SHA256SUMS；输出确定，已有目标拒绝覆盖。
- 按安装、日常使用、能力边界和版本说明整理公开文档，提供可直接下载的 Release 附件。

## 相比早期公开源码的累计变化

- 日常 CLI 收敛为 init、run、check、doctor；高级和兼容接口收纳到 help --all。
- 项目入口支持 Codex、Claude Code、Gemini CLI、Cursor、OpenCode 和 DSH；保留已有指令与用户修改。
- init 默认进行首次真实验证；run 保存验证范围与输入证据，修改后旧结果过期。
- 可恢复任务保存目标、验收条件、备注和交接信息，完成要求本任务的当前完整验证及人工验收。
- 可选 Codex 本地 SessionStart/Stop hooks，以及多 Agent 分工、复核和交接提示词。

## 升级

既有 harness.config.json 继续使用 schemaVersion 1，无需迁移。run --task 仍选择验证任务；run --work 才关联工作任务。用户定制应先合并保留，不覆盖已修改指令。

已有 Skill 用户替换完整分发目录并开启新会话；本地插件按宿主更新或重新安装，核实缓存实际版本。源码安装器和全局短命令继续保留，但都是可选用法。

## 验证与限制

- v0.5.0 冻结源码本地验证：132项测试通过，17文件；覆盖项目接入、真实命令验证、任务恢复与门禁、归档独立解压和搬迁。
- Codex CLI 0.154.0 与 Claude Code 2.1.167 在隔离目录实际安装通过；Claude 插件和 marketplace 严格校验无警告。实际安装路径内的 CLI 完成项目初始化、Bun测试与 doctor ready。
- DSH 本机未安装；原生插件通过7项基于官方固定提交的接口契约测试，尚未实测真实 profile 安装。兼容声明 >=0.2.2-rc.1 <0.3.0，developer preview 可能变化。
- 尚未用真实模型会话验收各宿主的技能发现与加载；宿主安装、配置和命令成功不能替代该证据。
- 分发包不包含 Bun、模型、凭据或额外宿主权限。发布 GitHub Release 不等于上架宿主公共插件目录或发布 npm。
