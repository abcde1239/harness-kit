# v0.5.0 — Standalone Skill and Native Plugins

**直接安装 Skill 或插件，在你常用的 Agent 中开始使用。**

v0.5.0 提供三种安装包：独立 Skill、Codex / Claude Code 插件，以及 DeepSeek Harness 原生插件。安装后，用自然语言接入项目、推进开发和运行验证，无需再到源码目录执行 `bun setup`。

## 本版亮点

- **Skill 可以独立安装。** 下载后放入宿主的技能目录，无需克隆源码或先安装全局命令。
- **Codex 和 Claude Code 可通过插件安装。** 同一份 marketplace 包支持两个宿主，添加本地来源后即可安装。
- **提供 DSH 实验插件。** 可通过 DSH 插件管理器接入 Harness Kit Skill，兼容范围见下方说明。

需要 **Bun ≥ 1.3.4**，Git 相关检查另需 Git。具体命令见[安装指南](/guides/installation)；附件中的 INSTALL.md 提供简要步骤，SHA256SUMS 用于校验下载。GitHub 的 Source code 下载用于源码开发，独立安装请选择上面的 ZIP。

## 升级说明

现有项目配置无需迁移。Skill 用户替换完整安装目录后开启新会话；插件用户按宿主方式更新或重新安装，并确认技能已出现。升级前保留自己的定制和已有项目指令。

## 兼容性

- DSH 插件适配 `>=0.2.2-rc.1 <0.3.0` 的 developer preview 接口，尚未在实际 DSH 环境中验证安装，建议先在测试项目中尝试。
- 安装或升级后，请开启新会话，确认宿主能找到 harness-kit 技能，再用于项目开发。
