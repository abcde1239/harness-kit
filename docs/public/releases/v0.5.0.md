# Harness Kit v0.5.0

**直接安装 Skill 或插件，在你常用的 Agent 中开始使用。**

v0.5.0 提供三种安装包：独立 Skill、Codex / Claude Code 插件，以及 DeepSeek Harness 原生插件。安装后，用自然语言接入项目、推进开发和运行验证，无需再到源码目录执行 `bun setup`。

## 本版亮点

- **Skill 可以独立安装。** 包内已包含完整 CLI，放入技能目录后即可使用，不依赖源码 checkout 或全局 harness 命令。
- **Codex 和 Claude Code 可通过插件安装。** 同一份 marketplace 包支持两个宿主，添加本地来源后即可安装。
- **新增 DSH 原生插件。** 通过 DSH 插件管理器接入，将 Harness Kit 注册为宿主 Skill，按需加载。
- **分发包一次生成。** 开发者可用 `bun run package:distribution <新的输出目录>` 构建全部安装包、安装说明和校验文件。

这个版本也包含此前完成的六宿主项目接入、可恢复任务和多 Agent 协作提示词。日常 CLI 保持四个入口：init、run、check、doctor；记录了验收条件的任务，需要当前验证与逐项验收后才能完成。

## 升级说明

已有项目配置继续使用 schemaVersion 1，无需迁移。Skill 用户替换完整安装目录后开启新会话；插件用户按宿主方式更新或重新安装，并确认实际加载的版本。保留自己的定制和已有项目指令。

## 兼容性与验证

- Windows 和 Linux CI 各通过132项测试；Codex CLI 0.154.0、Claude Code 2.1.167 已实测插件安装。
- DSH 原生插件针对 `>=0.2.2-rc.1 <0.3.0` 的 developer preview 接口适配，已通过接口契约测试，真实 profile 安装仍待验证。
- 各宿主的真实模型会话加载尚未完成验收，安装后请在新会话确认技能已被发现。
