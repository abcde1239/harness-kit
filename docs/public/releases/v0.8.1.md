# v0.8.1 — Agent Handoffs and Project Conventions

v0.8.1 支持在不同编码 Agent 之间交接同一任务，并为项目文件和临时产物增加可检查的目录约定。

- **任务交接。** 同一检出目录可凭任务 ID 通过 `harness task resume <id> --brief` 接续。换目录或机器时，用 `harness task handoff <id>` 生成交接摘要，并单独交付代码改动。[任务与验收](../reference/tasks.md)
- **职责和会话 Hook。** `harness roles` 可预览并写入受支持宿主的原生职责配置。Codex、Claude Code 和 DeepSeek Harness 可按宿主启用会话 Hook。DeepSeek Harness 使用 Claude Code Hook 桥接器及宿主 profile。[职责角色](../reference/roles.md) · [Hook 配置](../reference/configuration.md#optional-local-hooks)
- **项目指令与目录。** 共享协作指南使用 `.agent/guide.md`，各宿主保留自己的入口。通过 `documents.layout` 和 `files.layout` 约束文档、部署文件或维护脚本的位置，可按工作区设置。[目录规则](../reference/configuration.md#document-location-rules)
- **临时产物。** `check` 和 `run` 默认提示文档中对临时运行的引用。`artifacts clean` 保留能从根目录或工作区文档中识别出引用的运行。需要反复使用的预览可迁入项目设计目录，历史证据可按版本归档。[产物管理](../reference/artifacts.md)

## 安装与升级

选择对应宿主的完整安装包，然后开启新会话。更新已有项目的受管指令或 Hook 时，按[安装指南](../guides/installation.md)和[配置参考](../reference/configuration.md#optional-local-hooks)操作，并保留自定义内容。内置 CLI 需要 **Node.js ≥ 22.12.0 或 Bun ≥ 1.3.4**，Git 功能另需 Git。
