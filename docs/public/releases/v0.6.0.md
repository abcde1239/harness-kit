# v0.6.0 — Node.js Support and Agent Workflows

可使用 Node.js 或 Bun，在常用 Agent 中安装 Harness Kit，并按任务需要使用专业角色和编码习惯规则。

## 本版新增

- **支持 Node.js。** CLI、Hooks、安装器和三种安装包均支持 Node.js ≥ 22.12.0 或 Bun ≥ 1.3.4。项目原有的测试命令与工具链保持不变。
- **把链接交给 Agent 即可安装。** Agent 先询问默认或自选位置，再下载、校验并配置插件。安装器随 Release 提供，无需克隆源码或运行 `bun setup`。
- **按职责组织协作。** 提供产品、UX/UI、架构、前端、后端、测试、代码复核、文档和 Agent 专家提示词，配合任务单明确归属、依赖和交付要求。由宿主实际委派工具执行。
- **从项目提炼编码习惯。** 从你选定的代码归纳风格与架构规则，保留来源、适用范围和反例，形成可审阅、可选择采用的文档。安装包不包含个人画像。
- **统一英文 Agent 指令。** 维护的指令与提示词模板使用英文，保留用户原文、代码及回复语言偏好。首页与安装说明提供中英文入口。

## 安装

把以下请求交给 Agent：

```text
Read https://github.com/abcde1239/harness-kit/blob/v0.6.0/INSTALL.md.
Install the Harness Kit plugin from https://github.com/abcde1239/harness-kit/releases/tag/v0.6.0.
First ask whether I want the default installation location or a custom directory, then install and configure it for the current host.
```

也可手动选择安装包：

| 用途 | 下载 |
|---|---|
| 独立 Skill | [harness-kit-skill-0.6.0.zip](https://github.com/abcde1239/harness-kit/releases/download/v0.6.0/harness-kit-skill-0.6.0.zip) |
| Codex / Claude Code 插件 | [harness-kit-marketplace-0.6.0.zip](https://github.com/abcde1239/harness-kit/releases/download/v0.6.0/harness-kit-marketplace-0.6.0.zip) |
| DeepSeek Harness 原生插件 | [harness-kit-dsh-0.6.0.zip](https://github.com/abcde1239/harness-kit/releases/download/v0.6.0/harness-kit-dsh-0.6.0.zip) |

需要 **Node.js ≥ 22.12.0 或 Bun ≥ 1.3.4**，Git 功能另需 Git。附件中的 INSTALL.md 提供手动步骤，AGENT-INSTALL.md 提供 Agent 安装流程，SHA256SUMS 用于核对 ZIP 和安装器。具体命令见[安装指南](/guides/installation)。

## 升级

项目配置无需迁移。保留自己的定制后更新完整 Skill 或插件，并开启新会话确认技能已出现。插件用户按宿主机制更新原有来源；同名 marketplace 指向其他目录时，先检查路径冲突。以实际安装脚本的 `--version` 输出为准。

v0.5.0 的原有附件保持不变，仍需 Bun。新装或希望使用 Node.js 的用户请选择本版附件。

## 兼容范围

- Codex、Claude Code 提供原生插件包；Gemini CLI、Cursor、OpenCode 可生成各自的项目指令入口。
- DSH 插件仍为实验支持，适配 `>=0.2.2-rc.1 <0.3.0` 的 developer preview 接口；真实 DSH profile 安装与会话发现尚待验收。
- 角色提示词依赖宿主的委派工具，不提供后台调度或权限隔离。编码习惯提炼生成文档，不训练模型；采用前应审阅规则。
